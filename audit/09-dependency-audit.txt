## 3. Dispositions

### pillow 11.3.0 — 35 advisories (PYSEC-2026-2249/2252-2257/3451/3453/3454/3493-3496, 2874; fixes 12.1.1-12.3.0)
UNFIXED — blocked upstream: moviepy 2.2.1 (latest, no newer release) declares
`pillow<12.0,>=9.2.0`, and every fixed pillow version is >=12.1.0, so a strict
pip resolution of requirements.txt cannot include a fixed pillow
(verified: `pip install --dry-run -r requirements.txt` with
`Pillow>=12.3.0` → ResolutionImpossible). Risk assessment: the vulnerable
code paths (ImageCms transform mode mismatch, McIdas AREA mmap stride,
attacker-controlled image parsing) are not reachable in repo2video, which
only creates and encodes its own images via moviepy and never parses
untrusted image files. Revisit when moviepy publishes a release allowing
pillow>=12.1.

### click 8.1.8 — 1 advisory (PYSEC-2026-2132, fix 8.3.3)
UNFIXED — blocked upstream: gTTS 2.5.4 (the newest release) declares
`click<8.2`. Raising the click floor forces the resolver to downgrade gTTS
to 2.2.4 (verified), which is a worse trade. Exposure is limited to gTTS's
CLI entry point; repo2video imports the gTTS library and never invokes its
CLI. Revisit when gTTS allows click>=8.3.

### diskcache 5.6.3 — 1 advisory (PYSEC-2026-2447 / CVE-2025-69872, pickle deserialization; no fix released)
UNFIXED — no fixed version exists (5.6.3 is the latest). diskcache is a hard
dependency of manimgl 1.7.2 (verified via importlib.metadata), so it cannot
be removed from the render environment. The advisory requires a local
attacker with write access to the cache directory; repo2video does not use
diskcache directly and manimgl's cache lives in the user's home directory.

### setuptools 80.10.2 — 1 advisory (PYSEC-2026-3447, fix 83.0.0)
UNFIXED — deliberate pin `<81`: manimgl 1.7.2 imports `pkg_resources`,
which setuptools 81+ removed (verified: import fails with setuptools 83).
Upgrading requires an upstream manimgl change (1.7.2 is the latest release).
This also pins the venv used for CI parity; requirements.txt itself does
not pin setuptools.

### Verified-fixed in this environment
pillow 12.3.0 and click 8.5.0 were installed and the full test suite +
Pillow image save/load + gTTS import were verified working (77 passed),
demonstrating that the *code* is compatible with fixed versions; only the
transitive version caps above block shipping them in requirements.txt.

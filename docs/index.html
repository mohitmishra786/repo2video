repo2video

Paste any GitHub URL → Get a 1080p narrated code walkthrough video in minutes. Open source. Free.

View on GitHub Install

Code Analysis

AST-based Python analysis with multi-language support. Understands structure, functions, and classes.

AI Storyboard

Automatically plan video scenes from code structure using LLM or rule-based generation.

Video Rendering

MoviePy-based scene rendering with code display, color-coded backgrounds, and narration.

Text-to-Speech

Automatic narration via gTTS (free, offline) or ElevenLabs (premium voices).

Install

git clone https://github.com/mohitmishra786/repo2video.git
cd repo2video
pip install -r requirements.txt
streamlit run app.py

Or use Docker

docker build -t repo2video .
docker run -p 8501:8501 repo2video

## Description (500 chars max)
"Paste any GitHub URL and get a 1080p narrated code walkthrough video in minutes. repo2video is an open-source CLI + web tool that clones your repo, analyzes the codebase, generates an AI-powered storyboard, renders animations with code highlights, and narrates each scene via TTS. Supports Python, JavaScript, Java, and more. Output formats: MP4, WebM, GIF. Export subtitles as SRT. Runs 100% locally -- no cloud upload. Free forever."

Tech stack: Python (FastAPI + MoviePy), TypeScript (Next.js), tree-sitter for code analysis.
